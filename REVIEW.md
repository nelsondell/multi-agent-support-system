# Evaluator guide

One row per V4 criterion. `make verify` runs every offline check with no key and no network
(`make verify REPORT=1` records [`reports/verify.md`](reports/verify.md)); decisions are in
[`docs/adr/`](docs/adr/), the rollout in [`docs/pilot.md`](docs/pilot.md).

| Criterion (V4) | Evidence | Reproduce offline | Known limit |
| --- | --- | --- | --- |
| **Business & Challenge Fit** (9.5) | Pass-all **96/100** on sampled requests ([eval report](evals/eval_report.md)); the scenarios, human loop and confirmed write on one node and two replicas ([demo](docs/demo.md)); corpus filled for partial answers (T-53) | `make eval-offline` | Mock account data; open failures listed in [failure modes](evals/failure_modes.md); pilot volumes are assumptions |
| **Agentic Reasoning & Orchestration** (9.5) | Bounded replanning ([ADR 0001](docs/adr/0001-bounded-replanning.md), [supervisor](app/graph/supervisor.py)): **32/60** dependent requests completed against 19/60 without it, three runs ([planning report](evals/planning_report.md)) | `uv run pytest -q tests/test_replanning.py tests/test_plans.py` | No open loop by design; misses come mostly from knowledge not asking for the account fact, and from escalations a finding would have avoided |
| **Context, Knowledge & RAG** (9.7) | Hybrid BM25 + dense with RRF; abstention calibrated on 97 questions (AUC 1.000); recall@5 **0.939**, MRR **0.851** on 82 questions with reviewed gold; rerankers measured, Cohere opt-in ([ADR 0002](docs/adr/0002-reranker-off-by-default.md)) | `uv run pytest -q tests/test_retrieve.py tests/test_knowledge.py tests/test_ingest.py` | Benchmarks need the embedder's key; a chunk can cut a table; one reviewer for the gold |
| **Tool & Action Engineering** (9.5) | Merchant id never in a model schema ([tests](tests/test_tools.py)); one write, run once on the merchant's confirmation, audited ([ADR 0005](docs/adr/0005-write-behind-confirmation.md), [tests](tests/test_actions.py), [tools](docs/tools.md)) | `uv run pytest -q tests/test_tools.py tests/test_actions.py` | Mock backend |
| **Security & Identity** (9.3) | RS256 JWT, merchant from `sub`; roles, append-only audit, LGPD erasure, rate limit ([ADR 0007](docs/adr/0007-jwt-identity.md)); OWASP ASI01–ASI10 mapped ([security](docs/security.md)); red team **40/40** | `uv run pytest -q tests/test_security.py tests/test_adversarial.py` | Dev identity provider is a local key pair; rate limit per replica |
| **Memory, State & Resilience** (9.4) | Checkpoints on SQLite or Postgres ([ADR 0006](docs/adr/0006-postgres-for-replicas.md)); cross-replica handoff, replica killed mid-turn and serialized turns tested in CI; LangGraph retry and timeout on every node | `uv run pytest -q tests/test_memory.py tests/test_resilience.py tests/test_locks.py` | Replica tests need `TEST_DATABASE_URL`; the index is per node |
| **Human Oversight & Risk Management** (9.7) | `interrupt()` handoff: approve, reply or cancel; guarded rephrasing; TTL; the plan resumes after the reply ([human in the loop](docs/human-in-the-loop.md), 21 tests) | `uv run pytest -q tests/test_human_review.py tests/test_handoffs.py` | The operator's interface is the API |
| **Evaluation & Quality Engineering** (9.7) | **362 tests**; error analysis on 100 traces, labels drafted by a reasoning model, every row reviewed by the owner, 0 edits; one binary check per failure mode, replayed on every PR against the accepted recording's rates; held-out set of 80 requests no prompt was tuned on, labelled by the owner, blind, no model draft: **63/80** ([held-out report](evals/heldout_report.md)) | `make verify`; `uv run python -m evals.run_heldout` | Judge not validated: 5 labelled failures of its mode on the tuning set, none on the held-out; prompts were fixed on the tuning traces, 96/100 by the checks against 63/80 held-out by a person, labelled before T-60 |
| **Observability, Reliability & Cost** (9.2) | OpenTelemetry GenAI spans without content; cost per resolution, resolution by intent, escalations by reason, p50/p95 per node; four alerts with runbooks ([operations](docs/operations.md)); **US$ 0.00048** model spend per resolved turn | `uv run pytest -q tests/test_otel.py tests/test_telemetry.py` | GenAI conventions still in Development; prompt cache effect not measured |
| **Production Engineering** (8.6) | Clean-copy `make verify` with a committed tokenizer; CI on ubuntu with the network cut and on macOS; digest-pinned images, SBOM, trivy, gitleaks; `make scale` | `make verify` | Docker runs done by hand on macOS ([demo](docs/demo.md)); Linux only in CI |
| **Engineering Judgment** (9.8) | Each choice measured or recorded: [model](evals/router_benchmark.md), [embedder and threshold](evals/retrieval_calibration.md), [reranker](evals/rerank_benchmark.md), and the [ADRs](docs/adr/), with what was considered and not done | — | |
